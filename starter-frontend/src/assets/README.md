| File           | Purpose                            |
| -------------- | ---------------------------------- |

| `logo.png`     | PNG fallback (provide your own)    |
| `favicon.ico`  | Browser favicon (provide your own) |

Paths are wired in `src/environments/environment{,.prod}.ts`.
